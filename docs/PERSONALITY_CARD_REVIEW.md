# 形态人设卡检查记录

日期：2026-11-07

## 范围与结论

检查了全部 22 个形态。本轮调整其余 21 张角色卡，常态沿用此前已调整的版本；同时更新共享形态边界和新人格模板。形态 key、名称、权重、情绪分类及其他非表达配置保留。阿尔法的一行介绍和四张卡的戳一戳样例也作了针对性修改。

共性问题集中在旧规则与新规则互相抵消：角色卡重复注入旧版自然对话禁令，固定限制两三句话；主动示例虚构当前见闻、反复追问旧事；情绪与缺点被写成定时剧情；亲近常被沉默、辱骂、猜心或固定比喻挡住。

本轮删去重复规则和通用“商品／复制品”独白，移除固定句数上限，压缩重复的风格段落。各卡分别描述日常兴趣、双向关心、主动邀请与表达分歧的方式。日常样例只示意语感，不要求照抄。卡内原作经历、能力与虚构相遇归为背景，现实当下的信息仍依照输入和记忆。

这是表达与行为检查，未逐条考据原作设定；背景中的文学叙述保留一部分，不作为日常输出模板。本轮没有调用模型进行多轮生成，配置验证通过不等同于体验效果已被实测。

## 实际使用时的观察点

1. “我回来啦”：自然招呼，不自动盘问去向或检查吃饭睡觉。
2. 分享买到喜欢的东西：先一起开心，能有偏好与小玩笑，不立刻提醒健康风险。
3. “今天想黏着你”：自然回应亲昵，不自动退回守护宣言或自我分析。
4. “这件事先不聊，帮我看报错”：跟随新任务，后续没有新信息就不重提旧事。
5. 明确说不想回答：接受边界，不以“看穿你”继续追问。
6. 切换形态后用相同话题交谈：语气、兴趣和判断方式有差别，关系中的记忆与尊重保持连续。

完整生效建议重启弥娅进程：当前加载器会缓存共享配置，仅重新加载单张形态卡不保证共享配置一起刷新。
